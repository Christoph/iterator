# Features

* [Bound feature memory context](bound-feature-memories.md) - ✅ done · medium · Give each implementation contract a deterministic, capped set of the most relevant knowledge concepts.
* [Consolidate over-attached memories](consolidate-overattached-memories.md) - ⬜ pending · medium · depends: bound-feature-memories · Have knowledge consolidation identify stale, duplicate, and disproportionately attached concepts before proposing reviewed repairs.
* [Memorize retired plan commits](memorize-on-retirement.md) - ⬜ pending · large · Optionally route a completed plan's commits through the existing knowledge lifecycle when it is retired.
* [Onboard plan-less projects](onboard-planless-projects.md) - ⬜ pending · medium · Ensure Planning always offers a working goal, plan, and memory-initialization path in a new project.
* [Price model usage](price-model-usage.md) - ⬜ pending · large · Let projects optionally configure token prices per model and show calculated row and aggregate costs in Usage.
* [Keep Work blocked while agents run](reliable-work-blocker.md) - ⬜ pending · medium · Make the Work overlay accurately follow an active agent through dispatch, navigation, reconnects, and cleanup.
